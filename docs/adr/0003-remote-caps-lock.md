# ADR-0003：Caps Lock / 中英切换由被控制的 Mac 执行

状态：已实现，双机物理键盘验收待完成 · 2026-10-15

## 问题和证据

Caps Lock 的物理按住状态（`NX_ALPHASHIFT_STATELESS_MASK` / device bit）与大写锁定（`NX_ALPHASHIFTMASK`）不同。旧代码将锁定标志当作按下/松开，并将 A 的 flags 原样注入 B。本机创建事件探针证实 `CGEventCreateKeyboardEvent(57, ...)` 本身已经生成 `flagsChanged`，故不应仅通过修改事件类型修复。

在 macOS 27.0.1 上，模拟带物理状态标志的 Caps Lock down/up 没有切换当前输入源。目标端改为调用 TIS，并用 IOHID 读写真实的大写锁定状态。`IOHIDSetModifierLockState` 成功后，Quartz flags 不会立即更新；不能用它即时验证 HID 锁定结果。

## 决定

- A 控制支持 minor 3 的 B 时，复用 Fn 的 `UserKeyMapping` 管理，将 Caps Lock HID usage `0x7_0000_0039` 映射至 F18（keycode 79）。Fn 仍映射至 F19。
- F18 按下/松开发送 `CapsLock { epoch, down }`；丢弃重复，B 只接受当前 Controlled 会话的消息。此功能在远程控制期间占用 F18。
- 接收端短按在松开时执行一次动作。大写锁定已开启时先关闭；否则切换启用、可选择的 ASCII / 非 ASCII 键盘输入源。分别记住通过本功能观察到的两组输入源；记忆失效或首次使用时选择另一组中首个可用源。
- 读取 B 的 `com.apple.HIToolbox / AppleCapsLockPressAndHoldToggleOff`：显式关闭中英切换时按大写锁定处理。该偏好键不是稳定的公开 API；缺失时，只要存在两组输入源就启用切换。没有另一组时退回大写锁定。
- 长按阈值为 500 ms（引擎空闲轮询粒度最多约 100 ms），只切换一次大写锁定，松开不再切换输入源。阈值按 B 接收事件的时间计算，极端网络或队列延迟可能影响边界手势。
- TIS 在 macOS 主队列执行，完成并读回当前源后，输入引擎才处理后续字符。不会在 event tap 回调内等待。750 ms 未完成时报告错误、退出控制并取消尚未执行的请求。
- B 在会话开始和锁定操作后通过 `IOHIDGetModifierLockState` 读取真实状态，注入按键、鼠标和滚轮时使用 B 的锁定状态，不携带 A 的锁定/物理 Caps 标志。
- 正常切回、断线、紧急返回取消未完成手势，恢复 A 的映射。B 已选择的输入源和锁定状态保留。本机 Caps Lock 活动也会收回控制权。
- 发送端每秒检查新键盘。已有非空自定义映射的键盘仍跳过，避免覆盖用户配置；这些键盘上的 Caps Lock 隔离不保证生效。只清理本程序完整匹配的映射，同时兼容旧 Fn-only 残留。

## 协议兼容

协议 major 仍为 1，minor 从 2 增至 3，新增 envelope 字段 52。只有对端声明 minor >= 3 才启用 Caps 映射和新消息；否则保留旧键鼠路径。文件通道仍以 minor >= 2 判定。要使用新功能，两台 Mac 都必须更新。

## 范围和限制

这里切换的是系统输入源（例如 ABC ↔ 拼音），不是输入法内部未暴露成系统输入源的中英文模式。没有安装或启用在 B 上的输入法不会被创建或从 A 同步。首次目标源选择和固定长按阈值不是对系统私有策略的完整复制。

自定义键盘映射、实际 F18 快捷键、应用按文稿记忆输入源、第三方输入法、不同 macOS 版本，需按下表实测。探针验证通过不能替代双机验收。

## 验收

| 场景 | 预期 |
|---|---|
| A 控制 B，连续短按 10 次 | 每次仅 B 切换一次，A 输入源和锁定状态不变 |
| 切换后立即输入 | 松开后的第一个字符使用 B 新输入源 |
| 按住 0.7 秒并继续保持 | 仅 B 大写锁定切换一次，松开不切源 |
| A/B 初始大写状态相反 | 普通字符跟随 B，切回后各自保留状态 |
| B 本机按 Caps Lock | 收回控制权，本机操作正常 |
| 按下未松开就断线/紧急返回 | 未完成短按取消；没有延后切换、卡键或残留映射 |
| 新旧版本互连 | 普通键鼠及文件通道正常，不发送新消息 |
| 自定义映射和热插拔 | 不覆盖用户映射；新接入无映射键盘在扫描后被接管 |
| Fn、Fn 组合键、文件传输同时使用 | 原有行为正常 |

自动检查：`cargo test --workspace -- --test-threads=1`、`make lint`、`make app`、`swift test --package-path apps/macos`。显式平台探针：`scripts/probe-caps-lock.sh`，会临时切换本机输入源与 Caps Lock 并恢复。
